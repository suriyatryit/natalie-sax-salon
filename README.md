# Natalie Sax Hair & Beauty — Luxury Salon & Atelier

A high-end, responsive landing page and VIP reservation platform for **Natalie Sax Hair & Beauty**, located at Rosengatan 19 C in Kungsbacka, Sweden.

Built with **Next.js 15 (App Router)**, **Tailwind CSS**, and **Framer Motion**.

---

## ✨ Features

- **Dual-Theme Elegance**: Instant toggle between *Noir Luxury* (Dark Mode) and *Parisian Ivory* (Light Mode) with saved local preferences.
- **Hero Sanctuary Banner**: Rich video background with high color saturation, clear typography hierarchy, and authentic salon photography.
- **Curated Menu of Services**: Filterable service catalogue (Color & Balayage, Precision Cuts & Barber, Haute Updos, and Restorative Scalp Rituals) with pricing, duration, and feature highlights.
- **Lookbook & Transformations**: Client before-and-after showcase featuring blonde corrections, textured chignons, and chrome fades.
- **Sensory Sanctuary & Atelier Film**: Interactive film player with sound toggle, and collage of the salon interior, wash basins, and product boutique.
- **Meet The Founder**: Dedicated story and craftsmanship philosophy of master stylist Natalie Sax.
- **Interactive VIP Booking Modal**: Step-by-step appointment reservation with stylist selection, date/time scheduling, complimentary champagne toggle, and booking confirmation receipt.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 15 (App Router)](https://nextjs.org/)
- **Language**: TypeScript
- **Styling**: Tailwind CSS & Custom CSS variables
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Typography**: Google Fonts (*Cormorant Garamond* serif & *Montserrat* sans)

## 🚀 Getting Started

### Prerequisites
- Node.js 18.18+ or 20+

### Installation
```bash
# Clone the repository
git clone https://github.com/suriyatryit/natalie-sax-salon.git

# Navigate into project directory
cd natalie-sax-salon

# Install dependencies (use legacy peer deps for React 19 compatibility if needed)
npm install --legacy-peer-deps

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
